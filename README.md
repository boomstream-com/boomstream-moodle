# Boomstream Filter

Boomstream Filter converts string "[boomstream media[code_media] subscription[code_subscription] size[100x100]]" to embed player.

Example [boomstream media[xxxxxxxx] subscription[yyyyyyyy] size[100x100]]

Use Boomstream to manage videos and online broadcasts.

* Upload videos in different formats.
* Use DRM protection for Uploaded videos.
* Use online broadcasts.
* Sale videos via Boomstrem Pay Per View option. 

## Installation

1. Extract content of zip archive 
2. Upload extracted folder to filter
3. Navigate to Site administration > Filters > Manage filters
4. Enable Boomstream
