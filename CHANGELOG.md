# Changelog

Все заметные изменения плагина фиксируются в этом файле. Формат основан на [Keep a Changelog](https://keepachangelog.com/), нумерация версий — по `version.php`.

## [v1.3.2] — 2026-04-28

`version.php`: `2025022701 → 2026042801`, `release: v1.3.1 → v1.3.2`.

### Changed
- Хост в `src` найденного плеера теперь автоматически переписывается на сконфигурированный `hostname`. Если автор курса вставил, например, `play.boomstream.com`, а в настройках указан `play.boomstream.net` — в HTML страницы пойдёт `play.boomstream.net`. Раньше домен в `src` не менялся, и `hostname` использовался только для серверных API-вызовов. Подмена выполняется через `str_replace('://' . $identifier, '://' . $this->hostname, $matchedUrl)` — затрагивается только хост, путь и query сохраняются.
- Поле `hostname` стало опциональным. Раньше фильтр требовал заполненные `hostname`, `key` и `subscription` — иначе выключался полностью. Теперь обязательны только `key` и `subscription`. Если `hostname` пуст, плагин для каждой вставки берёт хост из самого `src` (`$identifier` из регулярки) — на него же уходят и API-вызовы, и подмена домена в этом случае становится no-op.
- Регулярка распознавания плеера собирается по принципу «4 публичных хоста + кастомный, если задан». Раньше при пустом `hostname` в шаблоне образовывалась хвостовая пустая альтернатива (`...|.org|)`), что в принципе ломало регулярку — но это было неважно, потому что до неё код всё равно не доходил. Теперь альтернатива добавляется условно через `if (!empty($this->hostname))`.
- В debug-вывод hostname теперь выводится как `(not set, will fall back to host from src)` вместо пустой строки, когда настройка не заполнена.
- SDK-скрипт адаптивного плеера (`https://<host>/assets/...`, типичный пример — `biframesdk.js`) теперь тоже переписывается на сконфигурированный `hostname`. Подмена выполняется внутри `_process` per-match — в той же «рабочей зоне», где для матча уже резолвнуты `$identifier` (host из `src`) и `$this->hostname` (target). Регулярка плеера сам SDK не ловит (требует 8-символьный `code` в пути), поэтому отдельный шаг: `preg_replace('://<identifier>/assets/' → '://<hostname>/assets/')`. Если `$identifier === $this->hostname` (например, `hostname` не сконфигурирован и сделан фолбэк на host из `src`) — подмена пропускается. В debug добавляется строка `Rewrote SDK asset URLs (N) on host <identifier> to: <hostname>`, если что-то реально подменилось.

### Notes
- Регулярка распознавания плеера, как и прежде, ловит `play.boomstream.{com,net,dev,org}` плюс кастомный `hostname` (если задан). Дев-домен (`.dev`) был добавлен ранее в этой серии правок.

## [v1.3.1] — 2026-04-28

Коммит: `33d070b` — *extend integration with hostname*.
`version.php`: `2025021701 → 2025022701`.

### Added
- В curl-вызовы Boomstream API добавлен `CURLOPT_FOLLOWLOCATION` — теперь корректно отрабатываются редиректы на стороне сервиса.
- В debug-вывод добавлены строки `API calls to host: ...` и `Result failed: <Message>`, чтобы было видно, на какой хост ушёл запрос и что именно вернул API при неуспехе.
- В корень репозитория добавлен `.gitignore` (`.idea/`, `.DS_Store`).
- В корне репозитория появился релизный архив `filter_boomstream_moodle34_2025022701.zip`.

### Changed
- API-вызовы (`/api/ppv/addbuyer`, `/api/ppv/info`, `/api/ppv/updatebuyer`) больше не идут на жёстко прописанный `https://boomstream.com`. Используется `$this->hostname` из настроек фильтра. Если `hostname` не задан — берётся хост из `src` найденного плеера.
- Тестовый медиа-код в `test.php` заменён с `FE7yDJpF` на `Am0TlUow`.
- В debug-выводе блок `Result:` теперь печатается только при `Status == 'Success'`. Раньше он печатался безусловно, что захламляло вывод при ошибках.

### Fixed
- Исправлено формирование `hash` для API. Раньше переменная `identifier`, в которой лежал хост из `src`, перезаписывалась на `$_SERVER['HTTP_HOST']` — это ломало привязку к хосту видео и попутно мешало корректно определять домен для API-вызовов. Теперь:
  - `hash` всегда считается как `<HTTP_HOST или host из src>|<userId>|<media>`,
  - `identifier` сохраняет исходный хост видео и используется как fallback для `hostname`.

### Release
- `release` в `version.php`: `v1.3.0 → v1.3.1`.
